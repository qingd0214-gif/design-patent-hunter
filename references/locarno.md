# 洛迦诺分类速查（常用类，用于缩小检索范围）

外观设计分类按《洛迦诺分类表》第 14 版。检索时带上类号能大幅减少噪声，但**分类由审查员给，可能与直觉不符**，所以类号只作辅助，主检索仍靠关键词。

| 类号 | 名称 | 常见产品 |
|---|---|---|
| 14-01 | 录音、通讯、信息再现设备 | 电视盒子、机顶盒、播放器 |
| **14-03** | **电信设备、无线遥控器** | **各类遥控器、无线遥控装置** |
| 14-02 | 数据处理设备 | 电脑、平板、键盘 |
| 14-04 | 显示界面与图标 | GUI、图标、界面 |
| 13-02 | 电力变压器、整流器、电池 | 电源、充电器、移动电源 |
| 13-03 | 配电与控制装置 | 开关、插座、控制器 |
| 10-05 | 检验、安全、信号装置 | 传感器、摄像头、门铃 |
| 26-05 | 灯、吊灯、壁灯 | 灯具 |
| 15-05 | 洗涤、清洁设备 | 吸尘器、扫地机 |
| 28-03 | 卫生与美容设备 | 剃须刀、电动牙刷、吹风机 |
| 21-01 | 游戏器具、玩具 | 手柄、玩具 |
| 12-16 | 车辆其他零部件 | 车载支架、车充 |
| 06-04 | 家具 | 桌椅、柜 |
| 09-03 | 包装容器 | 包装盒、瓶 |
| 24-01 | 医疗与实验设备 | 血压计、体温枪 |
| 02-04 | 鞋、袜 | 鞋类 |

## 用法

1. 认图后先按直觉选 1–3 个类号
2. 关键词检索为主，类号用于**核对**（若某件专利的类号与你判断差很远，说明它可能是非同类的近似设计，值得看）
3. 官方完整分类表：WIPO 洛迦诺分类（https://www.wipo.int/classifications/locarno/）

## 易错点

- 遥控器不一定是 14-03：车钥匙遥控可能落 12-16 或 08-07；玩具遥控落 21-01
- 带屏幕的遥控器可能同时有 14-03（装置）与 14-04（界面）两件专利，**要查两次**
- 苹果、小米这类公司常用「XX的主体」拆局部申请，同一产品会有 4–6 件局部外观设计
