# CNIPA 常规检索语法（已验证部分）

## 可用写法

| 写法 | 含义 | 实例 |
|---|---|---|
| `A B` | 空格＝AND | `遥控器 苹果公司` |
| `A AND B` | 交集 | `遥控器 AND 苹果公司` |
| `A OR B` | 并集 | `遥控器 OR 遥控装置` |
| `NOT` / `-` | 排除 | `遥控器 NOT 玩具` |
| `"词组"` | 精确短语 | `"媒体遥控器"` |

## 实操建议

1. **词越少越准**。先搜 `遥控器`，再用 `--max` 控制条数，人工扫名称。
2. **带申请人能砍噪声**：`遥控器 AND 苹果公司` 从全品类缩到 11 条。
3. **中文同义词要试**：遥控器 / 遥控装置 / 遥控设备 / 远程控制器；音箱 / 扬声器；手表 / 腕表。
4. 别在常规检索里写字段代码。`名称=(...)` 这类属于高级检索，**必须登录**且入口在「检索 → 高级检索」，本 Skill 不走那条路（易被风控拦）。

## 外观设计识别要点

- 外观设计公开号号段：`CN30xxxxxxxS`（`S` 结尾）。看到 `CN1xxxxxxxA`（发明）、`CN2xxxxxxxU`（实用新型）就说明筛选没生效。
- 申请号形如 `CN202130547907.0`，前 4 位是申请年份。
- 外观设计没有权利要求书，核心内容就是**视图 + 简要说明**。所以「专利文档」＝著录项目 + 视图，本 Skill 直接合成 PDF。
- 局部外观设计常见命名：`XX的主体`、`XX的前面部`、`XX的局部`。这类保护范围只及于虚线以外的部分，比对时要注意虚线界定的边界。
